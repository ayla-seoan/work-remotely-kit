## ① 자동 테스트 (pytest)

```powershell
cd work-remotely
uv run pytest -v
```

기대: `94 passed`

- 테스트는 `data/` 를 **임시 폴더에 복사해서** 써요. 진짜 데이터는 바뀌지 않아요.
- 오늘 날짜는 `2026-11-17` 로 고정돼요 (`tests/conftest.py`).

| 파일 | 개수 | 확인하는 것 |
|---|---|---|
| `test_tools.py` | 29 | 도구 함수의 계산 결과 (진행률 · 부하 · 정렬 · 기간), 쓰기 후 반영, 잘못된 값 거절 + **실패하면 아무것도 안 씀**, 지우기 도구 없음, 엑셀용 인코딩 |
| `test_remote.py` | 20 | 재택 근무: 근무 현황 요약 · 코어 타임 · 반차 예외, 출퇴근 중복 · 순서 검증, 본인만 쓰기, 휴가 겹침 · 반차 하루 · PO 승인 · 반려 이유, 사유 숨김, 체크인 · 미제출, 근무 시간 vs 기록 누락, 리마인더 (15시 · 19시 30분) |
| `test_mcp_protocol.py` | 6 | 진짜 MCP 클라이언트로 연결: 도구 15개 · annotations, 에러가 **메시지와 함께** `is_error` 로 오는지, 리소스 · 프롬프트, **별도 프로세스(stdio)** 로 띄워 쓰기 → 읽기, **`.mcp.json` 명령 그대로** 실행, 읽기 전용 모드에서 읽기 도구 10개만 보이는지 |

특정 테스트만: `uv run pytest -k issue -v`

## ② MCP Inspector (화면으로 눌러 보기)

```powershell
cd work-remotely
$env:TEAM_TODAY = "2026-11-17"
npx @modelcontextprotocol/inspector uv run python team_server.py
```

브라우저가 열리면 **Connect** → 아래를 하나씩 눌러 보세요.

> ⚠️ Inspector 에서 쓰기 도구를 누르면 **진짜 `data/` 가 바뀌어요.** 끝나면 `git checkout -- data/` 로 되돌리거나, 읽기 전용으로 띄우세요: `$env:TEAM_READONLY = "1"`
